# Pub-network-main-website
## Overview

This responsive landing page promotes my Telegram channel **[PUB NETWORK]** (e.g., "18+ content and bot services"), serving two purposes:

- **Learning project**: Matches The Odin Project's [Landing Page rubric](https://www.theodinproject.com/lessons/foundations-landing-page) pixel-for-pixel using semantic HTML, Flexbox layouts, and mobile-first CSS—no JS or frameworks.

- **Real-world use**: Official site linked in channel bio, with join button (`t.me/pub_network`), content previews, and subscriber call-to-action.
